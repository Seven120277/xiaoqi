# 小七的第一个仓库

从本机通过 SSH 推送的第一个提交。

## 常用命令速查

```bash
git status            # 查看当前改动
git add .             # 暂存所有改动
git commit -m "说明"   # 提交到本地
git push              # 推送到 GitHub
git pull              # 拉取远端更新
```

## 仓库信息

- 仓库名：`xiaoqi`
- 默认分支：`main`
- 远程地址：`git@github.com:Seven120277/xiaoqi.git`（走 SSH，不经过任何第三方镜像）

> 提示：国内晚高峰访问 GitHub 网页可能变慢或超时，push 走 SSH 通常更稳；拉大仓库时才需要用镜像前缀。
